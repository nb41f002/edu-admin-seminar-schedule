# 教育行政專題研討 · 授課時程與議題分配系統

純前端單頁應用（Single HTML），用於檢視與匯出「18 週授課時程／學生名冊／議題分配／統計分析」。製表：葉容辰。

## 如何開啟

1. 直接用瀏覽器開啟本目錄的 `index.html`（雙擊或拖曳至 Chrome / Edge / Safari / Firefox）。
2. 無需安裝、無需後端、無需建置；需能連線載入 Tailwind CDN 與 Google Fonts（Noto Sans TC）以獲得完整樣式。
3. 離線時仍可操作資料與匯出；僅外觀字型／部分樣式可能降級。

## 功能簡述

- **18 週授課時程**：週次、日期、主題、階段標籤、發表學生與議題、人數狀態。
- **學生名冊（17 人）**：學號／姓名排序、班別（由學號判定）、期中／期末週次與議題、協調狀態。
- **議題分配**：18 項議題之期中／期末人選與佔用狀態。
- **統計分析**：週次負擔與熱門議題長條圖。
- **搜尋**：即時過濾姓名、學號、週次或議題關鍵字。
- **匯出**：Word（.doc）、Excel（.xls）、瀏覽器列印／PDF。

### 業務規則（已內建）

- 期中週次概念：第 1～9 週；期末：第 10～18 週。
- 第 4 週（10/2）外師授課，不排學生報告。
- 議題人選超過 2 人 → 紅色需協調；僅 1 人 → 綠色充裕。
- 同週發表超過 3 人 → 紅色需協調；僅 1 人 → 綠色充裕。

## 如何匯出

頁面右上角按鈕：

| 按鈕 | 說明 |
|------|------|
| **匯出 Excel** | 下載 HTML 格式的 `.xls`（可用 Microsoft Excel / Google 試算表開啟）。內含：規範說明、18 週時程表、17 人名冊、議題佔用摘要。 |
| **匯出 Word** | 下載 HTML 格式的 `.doc`（可用 Microsoft Word 開啟）。版面含標題、製表、日期、規範框、時程表、名冊、議題摘要與簽核列。 |
| **列印 / PDF** | 開啟瀏覽器列印對話框，可另存為 PDF。 |

檔名範例：`教育行政專題研討_議題與週次分配表_YYYY-MM-DD.doc` / `.xls`。

> 提醒：此為「HTML 偽裝」的 `.doc`／`.xls`，非原生 OOXML／Binary Office 檔。以 Word／Excel 開啟時若出現轉換提示，選確認即可。

## GitHub Pages 部署說明（帳號／倉庫擁有者：nb41f002）

建議將本資料夾作為倉庫根目錄，或把 `index.html` 放在倉庫根目錄／`docs/`，再啟用 Pages。

### 方式 A：倉庫根目錄即為本應用

1. 建立公開倉庫（例如 `edu-admin-schedule`），擁有者為 **nb41f002**。
2. 將 `index.html`（與本 `README.md`）推送至 `main`（或 `master`）。
3. 至 **Settings → Pages**：
   - Source：Deploy from a branch
   - Branch：`main` / root（或 `docs`，視你放置路徑而定）
4. 儲存後約數分鐘可於下列網址開啟：

```text
https://nb41f002.github.io/<倉庫名稱>/
```

若 `index.html` 在倉庫根目錄，網址結尾通常為 `/`；若在子目錄，請帶上路徑。

### 方式 B：使用 /docs 資料夾

1. 將本應用檔案放入倉庫的 `docs/`。
2. Pages 來源選 `main` + `/docs`。

### 注意事項

- **CDN 相依**：頁面載入 Tailwind CDN 與 Google Fonts；若教室網路阻擋外部 CDN，樣式可能不完整，但資料與匯出仍可用。可考慮改為本機打包 Tailwind（進階，非本專案預設）。
- **隱私**：名冊含真實學號與姓名，建議倉庫設為 **Private**，或僅分享給修課同學；公開 Pages 等同公開名冊。
- **自訂網域**：可在 Pages 設定 Custom domain；DNS 需指向 GitHub Pages。
- **快取**：更新 `index.html` 後若看不到變更，請強制重新整理（Ctrl/Cmd + Shift + R）。
